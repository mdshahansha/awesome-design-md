Prescribed (Crisp), not extracted. Nothing in this file records a real xAI duration or curve.

| Interaction | Duration | Easing | Property | Reduced-motion behaviour |
|---|---|---|---|---|

| Toast | in 150ms, out 100ms | `{motion.ease-enter}` / `{motion.ease-exit}` | `opacity`, `translateY` 8px -> 0 | Opacity only at 100ms |
| List / card-grid enter | 150ms per item, `{motion.stagger-step}` 20ms, capped at 6 | `{motion.ease-enter}` | `opacity`, `translateY` 8px -> 0 | Stagger dropped, one shared 100ms fade |
| List / card-grid exit | 100ms | `{motion.ease-exit}` | `opacity`, `translateY` 0 -> 4px | Opacity only at 100ms, no stagger |
| Loading | 800ms linear, infinite | `linear` | `transform: rotate()`; skeleton `opacity` 0.4 -> 0.7 | Frozen; static mono "LOADING" label replaces the spinner |

Every exit is shorter than its entrance. Only `transform` and `opacity` animate, plus the paint-only `border-color` / `color` that SPEC section 6 explicitly permits — on a brand with no shadow, no accent and no scale-on-press rule, that paint change *is* the hover state, and a scale pop on a `{rounded.pill}` would distort its own radius. No ambient animation, consistent with the Overview's "no atmospheric backdrop".

### Needs approval

1. **Re-binding `text-input.borderColor` from `{colors.hairline}` to `{colors.body-mid}`.** The hairline is the field's only boundary and measures 1.08:1 against `{colors.canvas-soft}`; `{colors.body-mid}` #7d8187 reaches 4.36:1 on the same ground and is already in the palette, so no token needs inventing. Per SPEC section 2 step 3 the extracted binding is left exactly as found and the prose now scopes the hairline to decoration. A brand owner must decide whether the real product changes. The same question applies to `card-content`, `card-feature-product` and `ex-*` surfaces that bind `borderColor: {colors.hairline}` (1.12:1 on `canvas-card`).
2. **The outline pill's `rgba(255, 255, 255, 0.25)` border, at 2.13:1 over canvas.** This is the brand's single most-used interactive edge. The nearest passing value is `rgba(255, 255, 255, 0.40)` or flat `#5b5d61` (3.0:1), which visibly changes the signature pill. Defensible usage note if left as-is: the pill's label is `{colors.ink}` at 19.8:1 and the control is never identified by its outline alone — but WCAG 1.4.11 is not satisfied, and the file now says so.
3. **`{colors.mute}` on `{colors.canvas-card}` at 4.49:1, 0.01 short of 4.5:1.** Nearest passing value `#7e8288`. Usage note that makes the real hex defensible: restrict mute on card surfaces to 18px+ (`{typography.body-lg}`), where the large-text threshold of 3:1 applies; it already passes on `{colors.canvas}` at 5.06:1. Changing a brand hex for 0.01 is not worth it, but someone must sign that off.
4. **Prescribed focus ring.** `{colors.focus}` `#ffffff`, 2px outside the control with a 2px `{colors.canvas}` offset. The real site's focus treatment is unknown. A brand owner should confirm the ring reuses ink rather than introducing a colour — the alternative, a chromatic ring, would be the only accent on xAI's marketing surface.
5. **Error state borrows `{colors.accent-sunset}`.** The brand surfaces no semantic palette. Sunset orange reaches 6.54:1 on `{colors.canvas-soft}` and is paired with a mono helper line so colour never carries the error alone, but it is an illustration accent doing semantic work.

### Identity verdict

Still unmistakably xAI, and the additions pull toward the brand rather than away from it. The motion section argues from the file's own evidence — pills never scale because scaling distorts a 9999px radius; nothing fades in on first paint because a 96px weight-400 headline is painted, not revealed; there is no ambient drift because the Overview forbids an atmospheric backdrop. The focus ring is the brand's own white with a canvas offset, not a borrowed blue, which is the single change that would most have read as imported from another file in the collection. The Accessibility section is the most brand-specific thing in the file now: it says plainly that a system of 1.1:1 hairlines on three near-identical blacks has no perceivable component boundaries anywhere, which is a true and unflattering fact about this particular brand, not a generic caveat.

**Profile: Crisp, kept.** The roster assignment holds, though not by SPEC section 5's rule 2 as literally written — xAI's marketing surface is not a terminal, IDE or infra product. It qualifies on the adjacent evidence: a Geist Mono uppercase caption face used as the voice for every section eyebrow ("reads as a code comment", in the file's own words), an API as a shipped product, no photography, no gradient, weight 400 throughout, and an interactive vocabulary of one shape. That is a tool's posture, and "state change reads as instant; no entrance choreography" is exactly right for it. The nearest alternative is Calm via rule 4, which would be defensible on the sparse-editorial reading of the hero — but 250ms fades on a surface this austere would feel like marketing, which is the one thing the brand is at pains not to be. Not switched.
